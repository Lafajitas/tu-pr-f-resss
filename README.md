# Tu préfères ? 🎄

Mini site de « tu préfères » : 17 duels, thème Noël, fond pastel et flocons de neige.
Un seul fichier (`index.html`), sans dépendance.

## Mettre le site en ligne avec GitHub Pages

1. Pousse ce dossier sur un dépôt GitHub.
2. Dans le dépôt : **Settings → Pages**.
3. Source : **Deploy from a branch**, branche `main`, dossier `/ (root)`.
4. Après une minute, le site est disponible sur `https://<ton-pseudo>.github.io/<nom-du-depot>/`.
